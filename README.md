# Sales & Profit Analysis Dashboard

## Project Overview
This project was completed as part of **Data Analyst Internship – Task 4: Dashboard Design**. The objective is to create an interactive dashboard to help business stakeholders analyze sales, profit, order volume, and monthly sales trends.

## Tools Used
- Tableau Public
- Sample Superstore Dataset from Kaggle
- Microsoft PowerPoint

## Dataset
**Dataset:** Sample Superstore

Source: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

The dataset contains sales, profit, order dates, product categories, regions, and customer segments.

## Key Performance Indicators (KPIs)
- **Total Sales:** Overall sales generated.
- **Total Profit:** Total profit earned.
- **Total Orders:** Number of unique orders.
- **Profit Margin:** Total profit divided by total sales.

## Dashboard Visualizations
- Monthly Sales Trend — line chart
- Sales by Category — bar chart

## Key Insights
- Technology has the highest sales among the three product categories in the current chart.
- Monthly sales vary throughout the year.
- Sales and profit should be analyzed together to understand business performance.

## Files Included
- Tableau dashboard workbook (`.twb` or `.twbx`)

- Dashboard screenshot (`.png`)

## Conclusion
This project demonstrates the use of Tableau to create KPI cards, analyze sales trends, compare product categories, and develop interactive visualizations for business decision-making.
